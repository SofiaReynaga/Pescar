# 👗 FashionHub - Tienda de Ropa Online

## Descripción

FashionHub es un sitio web de e-commerce moderno y completamente funcional para una tienda de ropa. Demuestra capacidades de desarrollo web fullstack con HTML, CSS y JavaScript vanilla.

## 🌟 Características Principales

### Interfaz de Usuario
- **Navbar Responsivo**: Navegación sticky con gradiente atractivo
- **Hero Section**: Sección de bienvenida con CTA prominente
- **Diseño Moderno**: Gradientes, animaciones suaves y efectos hover

### Funcionalidades de Productos
- **Catálogo Dinámico**: 8 productos diferentes con emojis representativos
- **Modal de Detalles**: Vista completa del producto con selector de talla y cantidad
- **Búsqueda en Tiempo Real**: Filtra productos mientras escribes
- **Filtros Avanzados**:
  - Por categoría (Camisetas, Pantalones, Vestidos, Accesorios)
  - Por rango de precio
  - Combinables

### Sistema de Carrito
- **Carrito Lateral**: Panel deslizante con animación suave
- **Persistencia**: Guarda el carrito en localStorage
- **Gestión de Items**: Agregar, ver cantidad, y eliminar productos
- **Cálculo de Total**: Actualización en tiempo real
- **Indicador de Cantidad**: Badge en el navbar

### Experiencia de Usuario
- **Notificaciones Toast**: Mensajes emergentes elegantes
- **Animaciones Suaves**: Transiciones y efectos visuales
- **Responsive Design**: Se adapta a todos los dispositivos
- **Formulario de Contacto**: Funcional con validación

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica
- **CSS3**: Flexbox, Grid, Animaciones, Gradientes
- **JavaScript Vanilla**: Sin dependencias externas
- **LocalStorage API**: Persistencia de datos

## 🚀 Cómo Usar

1. **Clonar o descargar el repositorio**
2. **Abrir `index.html` en un navegador**
3. **Interactuar con la tienda:**
   - Buscar productos por nombre
   - Filtrar por categoría o precio
   - Ver detalles de productos en modal
   - Agregar al carrito
   - Realizar compra simulada
